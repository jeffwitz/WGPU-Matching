WGPU-Matching technical handbook
================================

Reading this edition
---------------------

This handbook follows the Diataxis learning path: tutorials for a first result,
how-to guides for practical work, explanations for scientific understanding,
and reference for exact interfaces and terminology. The Python interface is
the main route through the material.

The edition includes a scientific benchmark synthesis and primary sources.
Machine-readable arrays, full profiler traces and animated comparisons remain
in the repository and the HTML documentation. Their omission from print does
not imply that the corresponding experiments were not performed. Historical
reports have different resolutions and timing protocols; consult their raw
records before making a performance claim.
