Glossary and abbreviations
==========================

Technical abbreviations are defined independently on each page. Later uses
have hover definitions. Literal code and equations keep their exact spelling.

.. glossary::
   :sorted:

   4K
      a resolution class around four thousand pixels in width; exact image dimensions must also be given.

   8K
      a resolution class around eight thousand pixels in width; exact image dimensions must also be given.

   ALIKED
      A Lighter Keypoint and Descriptor Extraction Network via Deformable Transformation, the published model title.

   API
      application programming interface.

   BCE
      binary cross entropy, a classification loss.

   CI
      continuous integration, automated checks triggered by repository changes.

   CLI
      command-line interface.

   CNN
      convolutional neural network.

   CPM
      coarse-to-fine PatchMatch, a multiscale correspondence search.

   CPM-HOG
      coarse-to-fine PatchMatch using histograms of oriented gradients.

   CPM-WGPU
      the WebGPU implementation of coarse-to-fine PatchMatch in this project.

   CPU
      central processing unit.

   CSV
      comma-separated values, a tabular text format.

   CV
      computer vision.

   CVPR
      Conference on Computer Vision and Pattern Recognition.

   D2H
      device-to-host transfer, from graphics-device memory to processor memory.

   DaD
      Distilled Reinforcement Learning for Diverse Keypoint Detection, the published detector name.

   DeDoDe
      Detect, Don’t Describe — Describe, Don’t Detect, the published feature-model family.

   DIC
      digital image correlation: estimating material displacement by comparing image texture.

   DINOv2
      a self-supervised visual-feature backbone; the model name refers to the second DINO generation.

   DM
      DeepMatching, the hierarchical correspondence method.

   DoG
      difference of Gaussians, a scale-space response used to detect extrema.

   ECC
      enhanced correlation coefficient, the photometric alignment objective used here.

   ECCV
      European Conference on Computer Vision.

   EfficientLoFTR
      Efficient Local Feature Transformer, the semi-dense correspondence model.

   EOG
      Eye of GNOME, the image viewer used for local comparisons.

   EP
      execution provider, a runtime backend that executes model operations.

   FP16
      16-bit floating-point representation.

   FP32
      32-bit floating-point representation.

   FPS
      frames per second; these pair benchmarks count complete image-pair calls per second.

   GB
      gigabyte, one billion bytes.

   GiB
      gibibyte, 2 to the power 30 bytes.

   GIF
      Graphics Interchange Format, used here for alternating-image animations.

   GN
      Gauss–Newton, an iterative least-squares optimization method.

   GNOME
      GNU Network Object Model Environment, the desktop project name.

   GNU
      GNU’s Not Unix, the free-software project name.

   GPL
      GNU General Public License, a copyleft software licence.

   GPU
      graphics processing unit.

   H2D
      host-to-device transfer, from processor memory to graphics-device memory.

   HOG
      histogram of oriented gradients.

   HORG
      histogram of oriented and rotated gradients, the chirality-aware descriptor.

   HORG-DIC
      initialization of digital image correlation using histograms of oriented and rotated gradients.

   HTML
      HyperText Markup Language, the format of the compiled web pages.

   IC
      inverse compositional, a formulation that composes updates through the reference-image warp.

   IC-GN
      inverse compositional Gauss–Newton: an iterative image-alignment solver.

   ICCV
      International Conference on Computer Vision.

   INRIA
      Institut national de recherche en informatique et en automatique, the French research institute associated with DeepMatching.

   IOBinding
      input/output binding, a runtime mechanism for explicitly binding model buffers.

   IRLS
      iteratively reweighted least squares.

   JSON
      JavaScript Object Notation, a structured text format.

   KB
      kilobyte, one thousand bytes.

   KiB
      kibibyte, 1024 bytes.

   KL
      Kullback–Leibler divergence, a measure of difference between probability distributions.

   L1
      sum of absolute component values, used as a distance or norm.

   L2
      Euclidean norm, the square root of the sum of squared components.

   LK
      Lucas–Kanade, an iterative local image-alignment method.

   LNL
      Lunar Lake, the Intel graphics-platform codename in the measurements.

   LoFTR
      local feature transformer, a detector-free correspondence model.

   LOO
      leave one out, fitting without one observation to check its prediction.

   MAD
      median absolute deviation.

   MB
      megabyte, one million bytes.

   MiB
      mebibyte, 2 to the power 20 bytes.

   MIT
      Massachusetts Institute of Technology; MIT License names the associated permissive software licence.

   MLP
      multilayer perceptron, a fully connected neural network.

   MP
      megapixels, one million image pixels.

   MVS
      multi-view stereo, estimating scene depth from several calibrated images.

   NCHW
      batch, channels, height, width: a tensor-axis order.

   NHWC
      batch, height, width, channels: a tensor-axis order.

   NMS
      non-maximum suppression, retaining local peaks while suppressing neighbouring responses.

   ONNX
      Open Neural Network Exchange, a model interchange format.

   ORT
      ONNX Runtime, the inference engine for Open Neural Network Exchange models.

   P0
      phase zero, the initial diagnostic stage of the development schedule.

   P1
      phase one, the first implementation stage of the development schedule.

   P95
      95th percentile: the value below which 95 percent of the measured observations fall.

   PIL
      Python Imaging Library; image handling here uses its maintained successor Pillow.

   PNG
      Portable Network Graphics, a lossless image format.

   POI
      point of interest, a requested location for displacement initialization.

   PyPI
      Python Package Index, the public Python package repository.

   RaCo
      ranking and covariance, the learned keypoint detector.

   RAM
      random-access memory.

   RANSAC
      random sample consensus, robust model fitting by testing sampled subsets.

   RBF
      radial basis function, a function depending on distance from a centre.

   RGB
      red, green and blue colour channels.

   RMS
      root mean square.

   RMSE
      root mean square error.

   ROI
      region of interest, the image area allowed for analysis.

   RSS
      resident set size, the process memory currently resident in physical memory.

   RTD
      Read the Docs, the documentation hosting service and theme family.

   SELU
      scaled exponential linear unit, a neural-network activation.

   SfM
      structure from motion, reconstructing scene geometry and camera poses from multiple images.

   SHA
      Secure Hash Algorithm, a family of cryptographic file-digest algorithms.

   SHA-256
      Secure Hash Algorithm with a 256-bit digest, used to identify exact model files.

   SIFT
      scale-invariant feature transform.

   SiLU
      sigmoid linear unit, the activation x multiplied by sigmoid(x).

   TPS
      thin-plate spline, a smooth radial-basis interpolation model.

   UHD
      ultra-high definition; the tensile images here have 3840 × 2160 pixels.

   UI
      user interface.

   URL
      uniform resource locator, a web address.

   WebGPU
      the portable graphics and computation interface for graphics processing units.

   WGPU
      the project label for its WebGPU-based implementation; wgpu-py is the Python runtime binding.

   WGSL
      WebGPU Shading Language, the language used for the graphics-processor compute kernels.

   XFeat
      accelerated features, the published lightweight feature-model name.

   ZNCC
      zero-normalized cross correlation, comparing mean-centred and variance-normalized image intensities.

   ZNSSD
      zero-normalized sum of squared differences, a normalized photometric mismatch objective.
