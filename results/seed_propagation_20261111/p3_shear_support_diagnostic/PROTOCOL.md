# Shear-band oracle support and interpolation diagnostic

Protocol fixed before running: using the same three previously evaluated synthetic pairs at peak gradient 2.0, compare the same requested 64/64 grid centers under four IC-GN configurations: subset 64 or 32 pixels, each with linear or Keys cubic interpolation. The 32-pixel solver uses a 16-pixel grid so that all selected 64-pixel centers have exactly matching coordinates. Only these original centers are dispatched. Confirm the mapping numerically.

All variants receive the exact analytical local displacement and Jacobian at each center, used solely as an explicit oracle. Use the same input images, 30 iterations, tolerance 0.001, minimum normalized cross-correlation 0.65 and disabled outlier policy; no settings or decisions are fitted on this data. The original frozen G3 protocol remains unchanged. Score every visible original center and separately the 57 previously accepted but wrong windows, recording newly accepted false positives and previously correct windows lost. Record per-window results, original masks, interpolation and support, visibility, and per-pair counts. This is a small, post-hoc explanatory experiment with oracle initialization, not a production selector, a new gate or a test of image-derived initialization.
