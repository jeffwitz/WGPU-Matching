## Follow-up: final correlation and affine frontier

`register(..., include_zncc=True)` (single-scale) and `register_seeded(..., include_zncc=True)` run an additional WGSL pass on the final affine state, exposing an immutable `RegistrationResult.zncc` array. B-spline, linear and Keys interpolation are supported for uniform full windows. Inactive, rejected, outlier-flagged, invalid-support or zero-variance results have NaN scores; partial/weighted windows are explicitly unsupported. The correlation is computed after the final update, not necessarily the same value used in the internal convergence decision. GPU numerical validation includes a noisy subpixel affine state compared with independent NumPy bilinear interpolation. On a previously inspected 4K pair, all 1,658 valid score positions agree with the independent residual shader, with maximum absolute difference 0.000002981 ([raw results](zncc_parity.json)).

The opt-in `affine_frontier_seeds` kernel transports accepted neighbors using their six affine parameters, then takes a componentwise median of up to eight predictions. It returns seeds and an active mask for `register_seeded`; it does not apply consistency thresholds or iteration limits. A GPU test agrees with a NumPy median and an eight-neighbor identity case successfully runs both calls. On ten previously inspected 4K pairs, the active masks exactly match the NumPy median-front oracle and the largest parameter difference is 0.000115 (raw [data](frontier_parity.json)). This median differs from the two-neighbor P2 propagation rule. No material-boundary inference is implied. CPU readbacks and uploads remain between calls.

The solver suite with GPU enabled ran 386 tests, with 24 skips and one expected failure. Focused new GPU tests, Python lint and documentation build passed. A wheel was installed in a fresh environment and its packaged shader was exercised on the GPU. These are functional checks, not a performance qualification.

P4 remains **unfinished**: the complete production propagation policy and validation on actual image pairs still need to be connected; the final-correlation API remains limited to affine uniform full-window solves (single-scale for `register`). The changes are in solver commit `a8c3ca0` and [draft pull request #4](https://github.com/jeffwitz/live-dic/pull/4). P5 remains open. No production or full GPU-residency claim is made.
