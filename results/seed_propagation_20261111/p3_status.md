# P3 qualification status

The image-only pipeline uses the frozen P2 settings. The inverse-compositional Gauss–Newton (IC-GN) solver decides which windows are accepted; analytically known displacement is used only for scoring. Interpolated windows are reported separately.

- `p3_initial/evaluation/p3_initial_report.md`: ten rigid, ten affine and ten discontinuous synthetic pairs. No visible accepted centre has displacement error ≥2 px. The discontinuity in these cases lies on the 64 px grid, so no window support crosses it.
- `p3_perturbations/README.md`: five pairs each with shifted opening, doubled reference-texture noise, gain and offset, defocus, independent target noise, and periodic texture. No visible accepted centre has displacement error ≥2 px. In the shifted-opening cohort, 102 accepted windows have supports crossing the material boundary: centre accuracy does not validate their affine model over the whole support. All five periodic cases produce no accepted windows, so their false-acceptance rate is undefined.
- `p3_32px/README.md`: 197 false accepted among 259,569 visible accepted windows in the direct 32 px / 16 px development-grid experiment. The data are previously inspected development pairs.
- `p3_32px_coarse_transfer/README.md`: transporting accepted 64 px states and re-solving at 32 px gives 352,595 correct visible windows and no false accepted visible window on those same development pairs. On the separate confirmatory groups already inspected at the coarse scale, `p3_32px_confirmatory_transfer/README.md` reports 388,983/397,903 correct visible windows and no false accepted visible window, versus 283,437 correct and 250 false accepted for the direct fine-grid baseline.
- `p3_32px_shifted_transfer_diagnostic/README.md`: on five shifted-crack pairs, transfer yields 96,969 correct visible windows and no false accepted visible centre. However, 524 accepted fine supports cross the crack and 263 visible initializations use a source on its opposite side. The boundary is used only for this diagnosis. In `p3_32px_shifted_transfer_oracle_regions/README.md`, supplying the known boundary excludes these two situations while retaining 96,969 correct visible windows. This is an oracle control, not automatic crack segmentation.
- `p3_perturbations/shifted_opening/weighted/README.md`: unrestricted weighted interpolation gives 29 estimates with error ≥5 px on one shifted-opening pair, with sources across the material boundary. The `weighted_oracle_regions` companion uses the known analytical boundary as an oracle-only control and removes those errors; it is not an unknown-image result.
- `p3_external_tensile/README.md`: the six 10–60% synthetic traction images and frames 040, 100 and 199 are evaluated at native resolution against their archived analytical centred affine truth. No visible false acceptance was observed.
- `p3_external_experimental/README.md`: the masked Adrien pair gives 7,097 accepted windows out of 7,280 region-valid windows. No experimental accuracy is inferred. Its 86 additional interpolated values are reported separately in `p3_external_experimental/weighted_report.md`.

Scope clarification, 11 November: the user has excluded periodic textures from the intended speckle-initialization application. Their zero-acceptance result remains archived but does not block qualification of that application. G3 is not yet established for the complete intended operating envelope: shifted-opening supports can cross a discontinuity while still being accepted unless a material boundary is supplied; the fine-grid confirmation groups were already inspected at coarse scale. Earlier shear-band experiments in `../ndf_dic_20261109/frontier_generalization_20261109/README.md` also report 59/6,142 and 71/5,908 false accepted windows at peak gradient 2.0; they used an earlier propagation configuration and must not be attributed to the present frozen image-only pipeline. Experimental-image counts cannot establish accuracy without ground truth.

## Localized shear-band extension

**Superseded rounded-pixel scoring:** the exact-center correction below is the current result.

The frozen, image-only P3 initializer was evaluated on three paired textures at each peak shear gradient 0.33, 0.67 and 2.0; see `p3_shear_band_frozen_protocol/analysis/README.md`. At gradient 2.0 it falsely accepts 123/4,080 visible windows (3.01%), above G3's 0.5% limit. **G3 is rejected for this specified shear-band envelope.** The cohort is small and uses only synthetic data. For gradients 0.33 and 0.67 there were no visible false acceptances on these pairs. No threshold was changed.

All 123 falsely accepted windows at gradient 2.0 also converge to an error of at least two pixels when initialized with analytical local affine parameters sampled at rounded pixel positions. The oracle diagnostic is in `p3_shear_band_frozen_protocol/oracle_diagnostic/README.md`. This does not prove the cause of the bias; the finite affine window under highly curved deformation is a plausible explanation. The direct affine + normalized cross-correlation baseline already has 53 false acceptances on this same cohort, 46 of which are retained by the propagated result. Experimental-image accuracy remains unmeasured.

### Exact-center correction

The initial shear-band report used `truth_parameters`, which samples truth at rounded integer pixels. At these half-pixel window centers this changed the measured errors. The frozen outputs were rescored without changing inference, and oracle and zero controls were re-solved using the analytic field and gradient at each exact center; see `p3_shear_band_frozen_protocol/exact_center_analysis/README.md`. The corrected gradient-2.0 result is **57/4,080** falsely accepted visible windows (1.40%), not 123/4,080. G3 remains rejected against the 0.5% threshold. All 57 are also accepted and incorrect when initialized from the exact analytical affine parameters. The previous diagnostic and figures are retained but superseded. Future `shear_band` qualification computes exact analytical center truth; other families retain the prior truth convention pending their own audit.

## Support size, transfer, and unresolved-region follow-up

The paired oracle diagnostic `p3_shear_support_diagnostic/README.md` compares exact same centers at 64 and 32 pixels, with linear and cubic interpolation, on the three previously inspected gradient-2.0 pairs. Linear 64-pixel oracle solves give 4,240/4,761 correct with 323 false visible acceptances; 32-pixel oracle solves give 4,720/4,761 correct with no false visible acceptances. All 57 originally wrong windows are recovered with the 32-pixel oracle. This supports investigating local support effects, but neither proves the physical mechanism nor establishes a safe production method.

The image-derived 64-to-32 re-solve on those three pairs is `p3_shear_32_transfer_diagnostic/README.md`: 4,228/4,761 correct, 1/4,229 false accepted visible. Its new false result has 9.53 px error despite a source whose local error is 0.77 px. The separate predeclared `p3_shear_32_independent/transfer/README.md` tests five new texture/warp seeds from the same shear family: 5,405/7,013 correct and 5/5,410 false accepted visible, with all 47 formerly incorrect 64-pixel windows recovered and no previously correct window lost. This is a narrow same-family independent check, not a replacement of the frozen G3 gate or a broad qualification. Two pairs have no confirmed seeds on the far side of the band.

The post-hoc `p3_shear_unresolved_exploration/README.md` enables eager top-three hypotheses and unresolved-region local-affine escalation for those two pairs. It gains 331 and 314 correct windows but adds 21 false acceptances to the first pair. A subsequent post-hoc 32-pixel re-solve is in its `fine_transfer/README.md`; neither exploration changes the original G3 failure. Full scripted generation of six rotations cost 50.64 s for both cases including startup and data generation, not a GPU-kernel or production timing.

## Independent multifamily and shifted-opening fine transfer

A new predeclared 25-pair cohort covers translation, rigid, affine, heterogeneous and grid-aligned discontinuous fields, five pairs per family. On the original 64-grid centers, the 64-pixel initializer gives 30,164/31,207 correct; nearest-accepted transport followed by a real 32-pixel WebGPU IC-GN re-solve gives 30,620/31,207 correct, zero visible false acceptances among 30,620 accepted, and no previously correct window lost. See `p3_fine_transfer_multifamily_independent/fine/README.md`. This is not a dense 32/16-grid qualification, contains only five pairs per family, does not time the full pipeline and does not change the original G3 failure. On windows correct in both methods, the dimensionless gradient Frobenius error increases with the 32-pixel support (for example, heterogeneous gradient RMSE 0.0009 to 0.0025). The same texture seed can occur across families.

Five further predeclared discontinuous-opening pairs use a boundary at x=2123.52 pixels, offset from the grid. `p3_fine_transfer_shifted_opening_independent/fine/README.md` reports 6,938/7,158 correct visible fine results and no visible false acceptance. There are 141 visible fine initializations whose 64-pixel source support crosses the known boundary; 139 are subsequently accepted and correct at their center, which does not make their source support physically valid. No boundary label was used for inference. Five pairs do not qualify arbitrary fissures or real-image accuracy.

The synthetic generator's analytic displacement, full gradient and visibility are now evaluated at exact floating-point window centers for all six supported families in new `qualify_ndf_pair_icgn.py` outputs. Existing archived measurements are not modified; their rounded-pixel truth remains documented. The analytic evaluator is checked against the generator forward map and finite differences for every family.

## Decision, 11 November

P3 is closed with G3 **failed** for the specified extreme-shear envelope. The selected baseline and the limited, opt-in small-support retry are recorded in [p3_decision_20261111.md](p3_decision_20261111.md). Continue implementation in P4; do not reclassify this decision as a G3 pass.
