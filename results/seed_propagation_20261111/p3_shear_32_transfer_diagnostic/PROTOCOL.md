# Image-initialized 32-pixel transfer diagnostic

Protocol defined after the oracle support diagnostic and before this run: on the same three synthetic shear-band pairs at peak gradient 2.0, use the existing image-derived 64-pixel accepted states as sources for the unchanged nearest-valid-neighbor affine transport (`transfer_to_fine_grid`) at the original 64/64 centers. The source-selection algorithm receives no ground truth, visibility or shear-band labels; support availability depends on the accepted mask and the existing 96-pixel radius. For each available state, re-solve an affine 32-pixel support on WebGPU at the exact original center, using the 32/16 grid only to align centers. Keep linear interpolation, 30 iterations, tolerance 0.001, minimum normalized cross-correlation 0.65, and outlier filtering disabled. Every output is counted only if the 32-pixel IC-GN solve accepts it; transferred estimates alone are not measured results.

Report all original centers, accepted and correct visible, accepted errors >=2 px and accepted invisible, provenance sources, the 57 formerly wrong windows separately, and previously correct windows lost. Truth and band labels are used only for scoring after solving. Preserve original G3 result and thresholds; this is a post-hoc, three-pair diagnostic, not a predeclared independent validation or basis for a production switch. The safety of 32-pixel subsets on other data remains open.
