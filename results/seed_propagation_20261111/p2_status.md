# P2 development status

Digital image correlation (DIC) initialization selects image-derived hypotheses by the accepted status of the inverse-compositional Gauss–Newton (IC-GN) solver on a sparse subgrid. Normalized cross-correlation (NCC) supplies one of the candidates. Confirmed anchors are extended through affine state transport and per-window re-solves.

The frozen development search, stored in `p2_calibration/frozen_parameters.json`, selects a subgrid stride of 2, displacement consistency threshold 8 px, gradient consistency threshold 0.25 and three anchors per region. Across the 20 development pairs this gives 21,366 correct windows and no accepted visible window with an error of at least 2 px. These data were used for calibration and are not independent validation.

On the previously seedless pair `17051005`, the second image-ranked rotation provides an anchor; propagation obtains 712 correct windows. On `17051007`, the first three global rotation hypotheses provide no seed at stride 4. A development-only fallback fits local affine models from image-derived hard matches using WebGPU Shading Language (WGSL) kernels. It obtains 736 correct windows with no visible false acceptance; the analytic initialization obtains 735. The analytic result is not a mathematical upper bound. The matched control performs the same 64 solver calls and obtains 6 correct windows. These are diagnostic observations on two development pairs.

The held-out groups 21000000 and 22000000 have been evaluated. On heterogeneous pairs, 23,920 of 24,994 visible windows are correct, with no false accepted visible window. On translations, 28,698 of 29,706 visible windows are correct, also with no false accepted visible window. See `p2_independent/evaluation/README.md` for paired results and maps.

That initial G2 experiment was incomplete: the translation baseline rejected 20/20 near-identity affine prefits under the existing 0.03 minimum linear-deviation criterion, while its neural residual was disabled. Consequently its zero translation successes did not establish a meaningful non-regression comparison. The local affine fallback had then been exercised on one difficult development pair rather than systematically validated. The subsequent measurements below address these two limitations; integrated execution time remains open.

As an additional post-hoc diagnostic, the existing neural-residual plus local-correlation pipeline obtains 23,875 correct translation windows on the same 20 pairs, compared with 28,698 for the new pipeline. This does not replace the planned baseline; see `p2_translation_diagnostic/README.md`.

The fixed local affine fallback was subsequently evaluated separately on all 20 development pairs: 21,367 correct among 22,416 visible and no visible false acceptance. This post-hoc development validation preceded selection and inspection of the fresh confirmatory results, although their input diagnostics were being computed concurrently; see `p2_local_validation/README.md`.

The fresh confirmatory groups 23000000 and 24000000 use the repaired baseline. On heterogeneous fields, 23,570 of 24,641 visible windows are correct; the pair-bootstrap mean gain is 23.65 percentage points with 95% interval [14.78, 35.19]. No visible false acceptance occurs. On translations, 28,641 of 29,459 are correct against 25,173 for the corrected baseline; no pair regresses. The numerical G2 criteria pass; see `p2_confirmatory/evaluation/README.md`. Qualification of the integrated execution time remains open.

Scope clarification, 11 November: full end-to-end timing is not one of the G2 acceptance conditions written in section 5 of `CdC_Codex.md`; it belongs to the subsequent performance work. It was added as a requirement to the separate confirmatory protocol before the new results were inspected. Thus the original G2 numerical criteria pass on the new groups, while that stricter, separately declared qualification remains incomplete until timing is measured. The prescribed groups 21000000 and 22000000 were examined before the baseline repair, so their corrected translation comparison is post hoc rather than a pristine confirmation.
