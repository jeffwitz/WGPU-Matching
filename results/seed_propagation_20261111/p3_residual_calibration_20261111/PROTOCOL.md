# Development-only calibration of image residual suspicion

Recorded before inspecting residual scores. On the three previously studied synthetic shear-band cases at peak gradient 2.0 in seed group 59000000, compute image-only zero-mean normalized cross-correlation (ZNCC) scores on each accepted 64-pixel affine window: full window and each of four equal quadrants. These are diagnostics calculated in a separate WebGPU pass; the solver itself exposes acceptance status but not the scalar scores. Full-support samples outside the target image or locally constant patches have unavailable scores.

After scores are fixed, use exact analytical center truth only to assign development labels. Compare two scalar rules: full-window ZNCC and the minimum of quadrant ZNCC. For each rule, flag low scores and unavailable scores. Choose the deterministic score threshold that detects the greatest number of incorrect accepted visible windows subject to marking at most 5% of correct accepted visible windows as suspect. Count unavailable scores in the 5% budget. If no threshold meets it, do not produce a usable classifier. Choose the rule with greater error recall; if tied, prefer full-window ZNCC. Record all thresholds, confusion counts and unavailable scores; no test images enter calibration. The 5% cap is an experimental alert-budget criterion, not a measurement-accuracy guarantee and not a change to any G3 threshold.

Freeze the chosen rule and threshold, then evaluate the image-only 64→32→16 recovery with that classifier on new test textures. Report missed false acceptances, correctly flagged cases, false alerts, coverage and false acceptances after each solve. The 16-pixel result must be solver-accepted and must pass the existing 8 px / 0.25 gradient consistency tests. Keep the 64-only, status-only and residual-guided paths separately. Report scores unavailable to the classifier, runtime, transfers and final accuracy. Do not use truth, test labels or spatial band coordinates for inference.
