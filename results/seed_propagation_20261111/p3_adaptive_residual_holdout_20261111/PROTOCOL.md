Report each cohort and pair separately: false accepted, visible coverage, newly recovered and lost correct, true-error detection and missed errors, correct windows flagged as suspect, no-score fraction, fine-stage attempt and acceptance counts, final provenance and wall time including GPU transfer and reference setup.
