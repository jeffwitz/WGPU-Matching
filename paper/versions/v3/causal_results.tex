\subsection{Which component produces the improvement?}
The most informative comparison holds the coarse matcher, orientation bank, affine prefit, twenty heterogeneous pairs and native IC-GN settings fixed. Only the nonlinear residual and local correlation are changed. Table~\ref{tab:causal} reports the original one-pass results and a subsequent propagation experiment using those accepted states. All rows share 22,416 visible requested windows. The coarse matcher, prefit and NCC operate on a $192\times108$ raster; the correlation solver uses native $3840\times2160$ pixels. Thus ``affine only'' does not mean ``without a learned matcher''.

Adding NCC to affine initialization recovers a net 14,196 correct windows in one pass: pooled coverage rises from 9.23\% to 72.56\%. After propagation, however, the corresponding gap is only 736 windows, or 3.28 percentage points (88.84\% versus 92.13\%). This difference changes the interpretation of the component. NCC is valuable not only for immediate coverage, but also for providing an additional seeded pair and reducing propagation effort: median propagation rings fall from 13 to 3 in this implementation. The baseline must therefore include propagation before claiming that a more expensive initializer is necessary.

Propagation adds 4,385 correct windows to affine + NCC, a 19.56-point pooled gain, without a new visible false acceptance. Affine alone gains 17,845 windows, but retains one false initial acceptance. That state has a 9.466-pixel error on pair 16051009/16091009 and is already present in the initial pass. Its presence is reported rather than removed using truth. No accepted invisible windows occur in these four propagation comparisons.

Adding the tested NDF residual when NCC is present loses 3,094 one-pass successes. Windowwise accounting identifies 245 successes unique to the residual and 3,339 successes lost to it. The mean paired coverage change is $-13.15$ points, with a 95\% pair-bootstrap interval of $[-16.43,-9.69]$. After propagation the residual still yields 734 fewer correct windows and one fewer seeded pair. The operational baseline therefore omits this residual. This conclusion does not reject an untested network explicitly trained for residual prediction after rectification.

\subsection{Separating geometric mismatch from descriptor discrimination}
The earlier material-frame oracle provides a mechanistic control. On the rigid diagnostic, the compact CNN improves from 0/486 to 474/486 top-ranked correct correspondences within five pixels after affine compensation. DeDoDe-B improves from 0/486 to 485/486. The CNN therefore retains discriminative information that is inaccessible under the uncorrected support geometry. On the affine diagnostic its result improves from 5/431 to 290/419, while DeDoDe-B improves from 218/431 to 413/419. These denominators differ because compensated support validity changes; they must not be treated as paired rate differences over an identical eligible population.

This first oracle uses analytical material-frame rectification, including the anchor position, and is not a usable initializer or a proof about Jacobian-only inference. The heterogeneous diagnostic is also small: 32 queries, with 29 or 30 repeatable queries depending on support validity. Its purpose is to locate a failure mechanism before further training. The result supports geometric compensation, but cannot itself establish a practical recovery rate or runtime. In particular, its ZNCC control has no local translational optimization around detected candidates, so its lower rank-retrieval score does not disqualify photometric refinement.

\subsection{What the WebGPU implementation has actually established}
A separate four-pair comparison replaces host-orchestrated propagation by a resident GPU frontier while preserving pixels, initial hypotheses and solver settings. Both paths recover exactly 4,695 of 4,900 visible windows, with no visible false acceptance. Accepted masks, parameters, anchor identities, parent links, generations, attempts and rejection reasons agree exactly in the archived comparison. This establishes numerical preservation on the tested configurations, beyond agreement of aggregate counts.

Within that frontier the target and seed states are uploaded once. Proposed affine states, active masks and solver states remain on the same device across passes; an eight-byte counter is read per pass and final outputs are recovered once. The memory benefit is thus structural: large per-window intermediate arrays no longer make a host round trip at every ring. This result does not establish residence of the coarse learned matcher or all anchor processing, and no latency speedup is inferred from parity alone. It is an implementation contribution separate from the scientific coverage improvement.
